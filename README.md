# 🎯 Dart Basics Learning Project

This repository contains a collection of Dart programming examples and exercises designed to help learn the fundamentals of the Dart programming language.

## 📁 Project Structure

The project includes examples of:
- 👋 Hello World introduction
- 📝 Variables and data types
- 🗃️ Maps and collections

## 📑 Files
- `01-hello-world.dart` - Basic introduction to Dart programming
- `02-variables.dart` - Examples of variable declarations and types
- `03-maps.dart` - Working with Dart maps and collections

## ⚙️ Requirements
- Dart SDK installed on your system
- A code editor (VS Code recommended with Dart extension)

## 🚀 Running the Examples
To run any example file:
```bash
dart run filename.dart
```

For example:
```bash
dart run 01-hello-world.dart
